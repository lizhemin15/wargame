## 坑
- tiny_http `Response::empty()` 返回 `Response<Empty>`，与 `Response<Cursor<Vec<u8>>>` 类型不符 → 用 `Response::from_string("").with_status_code(204)`
- `Response::with_header()` 消费 self（Move 语义）→ 须 `let resp = resp.with_header(...)` 重新绑定
- `serde_json::json!` 对 `HashMap<String, UnitClass>` 要求 `UnitClass: Serialize` → 手动 map 成 JSON Value
- 渲染插件契约必须顶层返回工厂函数（同前）
- **前端 JS 命名不一致**：render() 调 `highlight()` 但函数叫 `highlightMoveTargets()`，编译无感（纯 JS），只运行时报错。做法：改完 web/ 记得 `cargo build --release` + `systemctl restart wargame`（index.html 经 include_str 嵌入）。
- **DNS 路由可能指向错隧道**：`wargame` 的 CNAME 一开始指向 68f255f2...（非 ccui d9356370...），是历史遗留错误记录。cloudflared route dns 报 "already exists" 即需 API PUT /dns_records/{id} 修正 content。
